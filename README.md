# Transcriptomic Analysis of Breast Cancer

## Overview

This project focuses on the transcriptomic analysis of RNA-seq data to investigate the association between gene expression profiles and response to neoadjuvant treatment in breast cancer.

The aim is to identify molecular patterns and candidate biomarkers associated with treatment response.

## Repository contents

- `FINAL_CODIGO.R`: R script containing the transcriptomic analysis pipeline.
- `resultados_TFM/`: Directory intended to store the outputs generated by the analysis.

## Analysis workflow

The analysis includes:

1. RNA-seq data import and clinical metadata integration.
2. Quality control and exploratory data analysis.
3. Filtering of low-expression genes.
4. TMM normalization and log-CPM transformation.
5. Principal component analysis (PCA).
6. Differential expression analysis using limma-voom and DESeq2.
7. Pathway analysis using GSVA.
8. Exploratory machine learning analyses.

## Requirements

The analysis requires R and the packages specified in the script.

## Input data

The input data files are not included in this repository. Before running the script, ensure that the required input files are available and that their paths are configured correctly.

## Reproducibility

Before running the script, check that the input file paths and output directories are configured correctly.
